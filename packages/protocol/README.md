# @bbbbbapp/protocol

Protocol-2 event validation and RFC 9180 HPKE helpers for bbbbb. The package exports the Activity/Attention event contract, strict UTF-8 bounds, canonical envelope validation, P-256/HKDF-SHA256/AES-128-GCM sealing/opening, write-authority types, and safe relay-URL normalization.

It contains no protocol-1 compatibility surface.
