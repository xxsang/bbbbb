# Install bbbbb

Start with the iPhone app, then choose one guide:

| You are using | Start here |
| --- | --- |
| Coding agent | [HTTP Source](HTTP_SOURCES.md#coding-agent) |
| Webhook, service, or script | [HTTP Source](HTTP_SOURCES.md) |
| `bbbbb run` command wrapper | [CLI Source](CLI_SOURCES.md) |
| macOS | [macOS setup](MACOS.md) |
| Linux or SSH | [Linux setup](LINUX.md) |
| Windows | [Windows setup](WINDOWS.md) |

HTTP is the default and needs no CLI. Use the CLI only to wrap finite macOS or glibc Linux commands. Finish by sending one test update.
