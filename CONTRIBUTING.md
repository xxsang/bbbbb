# Contributing

Contributions must preserve the documented protocol, privacy boundary, bounded inputs, and redacted logs. Run `npm ci`, `npm run check`, and `git diff --check` before submitting a patch.

Do not include proprietary iOS source, credentials, production identifiers, user data, copied third-party code without compatible terms, or generated build output.

This project uses Apache-2.0 for inbound and outbound contributions. Every commit must include a `Signed-off-by` line certifying the [Developer Certificate of Origin 1.1](https://developercertificate.org/); no CLA is required.
